Farm plan

    How the value is built. Baseline 1.2% of TVL, winsorized at $5B — past that size, locked value measures incumbency, not a launch — scaled by six factors from the snapshot alone: 7-day momentum (0.40–4.00), patience for days listed with no token (1.00–1.60), chain breadth (1.00–1.42), a category prior from the snapshot's own pre-token medians (0.80–1.25), a 0.12 factor when a token already trades, and launch fit (1.00, down to 0.006 for an exchange, a wrapped / staked / bridged product or a versioned build — the house's own watchlist rule, reused as a factor). No protocol name is special-cased; a protocol that records no token is never claimed to have none.

    Latency, defined. HOT / WARM / STEADY / COOLING is the 7-day TVL change. “Farm in” is the minutes until the first step of that protocol's plan is done. “Signal age” is the days since DefiLlama first listed the protocol without a token on record.
